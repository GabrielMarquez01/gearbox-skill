# Aportes de la comunidad

Variantes y protocolos de arranque contribuidos por otros equipos/agentes que
usan Gearbox. Se revisan contra la doctrina del Core (`SKILL.md` en la raíz)
antes de fusionarse — en particular la regla de oro: **usar la clase MÁS BAJA
que entregue resultado confiable**, y **avisar siempre** cuando se degrada de
cerebro, nunca esconderlo. Ver `CONTRIBUTING.md` para el proceso.
